# RareQ-reproducible-scripts
Scripts for reproducing the data analyses in RareQ's manuscript.

1. Complete scripts for all new analyses, including the Alzheimer’s disease (AD) microglia and renal cell carcinoma (RCC) case studies

2. Package versions are listed in the Package_Version.MD file and fixed random seeds are provided within the code and folder (Figure_13R/secure_seeds.RData).

## Datasets
1. [AD](https://zenodo.org/records/17190972/files/Alzheimer.rar?download=1) in Fig.R2 and Table R1, and [RCC](https://zenodo.org/records/17190972/files/Xenium_Human_Kidney_RNA_Protein.rar?download=1) data can be downloaded from Zenodo.
2. PBMC simulated datasets (Sim-PBMC 1,2,3) in Fig.R1,3,13 can be generated according to the [code](https://github.com/xiaolab-xjtu/RareQ/tree/main/Simulation) in RareQ repository and [data](https://zenodo.org/records/17190972/files/simulation.rar?download=1) from zenodo.
3. Mouse brain spatial transcriptomics in Fig.R7-11,14 from [EEL FISH](https://zenodo.org/records/17190972/files/smFish.rar?download=1) and [Xenium](https://zenodo.org/records/17190972/files/Xenium_Mouse_brain.rar?download=1) platform can be downloaded from zenodo. 
4. [Jurkat](https://github.com/xiaolab-xjtu/RareQ/blob/main/data/Jurkat.RDS) cell line data in Fig.R1f,g can be download from RareQ repository.
